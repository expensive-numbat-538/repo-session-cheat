# R.E.P.O. Session Toolkit — feature reference

R.E.P.O. Session Toolkit brings crew planning and equipment notes into one section-based interface. Session records provides the third part of the workflow.

| Section | Description |
|---|---|
| Crew planning | Character or team groups presented with the context needed to organize a session. |
| Equipment notes | Equipment categories and the associated selection or configuration options. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
